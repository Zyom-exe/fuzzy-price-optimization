    How the model got this price, in 6 steps
    Score (0 to 1)
    How well a word fits a number. Demand 8/10 is 0.7 "High" and 0.3 "Medium", because 8 sits between the two.
    Rule strength
    How well a rule fits right now. A rule with "AND" is only as strong as its weakest part.
    Simple average (Sugeno)
    Each rule proposes a fixed change. The model averages them, giving stronger rules more say.
    Shape-based average (Mamdani)
    Each rule's change is a triangle, cut down to the rule's strength. The answer is where the combined shape would balance.
